# Koda Web UI/UX Audit — 2026-11

Live audit of koda-wk (`:8030`, deployed `72c30222`) with real data, at 1440 px and 390 px, plus Lighthouse
snapshots. Fixes land as slices in [`MASTER-PLAN.md`](./MASTER-PLAN.md) (Status table + Decisions log); this
file tracks every finding until it is fixed or ruled out.

Status values: **Fixed** (on a branch, with the branch name), **Open**, **Needs decision**, **Won't fix** (with the reason).
Severity: **High** = wrong or broken information, accessibility failure; **Medium** = confusing or inconsistent;
**Low** = polish.

## Round 2 — 2026-11-12, every page

Method: a scripted Playwright sweep of 46 routes (every page with real data) in dark 1440 px, dark 390 px and
light 1440 px, running axe-core (WCAG 2.1 AA) and checks for raw enums/ids, horizontal overflow, touch targets,
console errors and load time; then a screenshot review of each page. Run twice: against the deployed build and
against `feat/web-ux-audit-polish`. Every dark-mode contrast failure in the deployed run (fleet jobs, fleet
analytics, threads, ticket, job, logs, fleet overview, runners) is gone on the branch (R1-2), as are the fleet
filter names (R1-10). The thread-start form labels were already fixed on main by #439.
